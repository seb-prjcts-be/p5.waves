Example 16 — all 34 waves

Wave Chart

All 34 wave formulas rendered simultaneously as animated bars. Bar height = current output of each wave at the same time input. A live reference — index numbers match { wave: i }.

Core snippet
for (let i = 0; i < Waves.count; i++) {
  const v = Waves.wave(t * 28, {
    wave:  i,          // direct index → each bar = one formula
    range: [-amp, amp]
  });

  const h = abs(v);
  const y = v < 0 ? midY : midY - h;
  rect(i * barW, y, barW - 2, h);
}
