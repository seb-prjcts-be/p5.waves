Example 04 — P2D Renderer

Contour Map

30 horizontal wave lines stacked with a progressive phase offset per row. The overlapping contours create a topographic map illusion. Explicit P2D renderer — confirms Waves.wave() works renderer-agnostic.

Core snippet
// P2D renderer — Waves.wave() is renderer-agnostic.
// 30 contour lines, phase offset i * 0.24 staggers the rows.

createCanvas(460, 460, P2D).parent('sketch-container');

// In draw():
for (let i = 0; i < LINES; i++) {
  const y0    = map(i, 0, LINES-1, 30, height-30);
  const phase = i * 0.24;

  beginShape();
  for (let x = 0; x <= width; x += 4) {
    const dy = Waves.wave(x * 0.011, {
      wave: 'wobble sine', t: t + phase, amplitude: 13
    });
    vertex(x, y0 + dy);
  }
  endShape();
}
