Example 12 — color output

Wave Color Field

Two waves interfere across x and y to drive hue and brightness. Sampling wave(x+y) and wave(x−y) creates diagonal colour landscapes — a 2D field that flows as t advances.

Core snippet
colorMode(HSB, 360, 100, 100);

for (let y = 0; y < height; y += 4) {
  for (let x = 0; x < width; x += 4) {
    const hue = Waves.wave(x * 0.007 + y * 0.005, {
      wave:  'meta sine', t, range: [0, 360]
    });
    const bri = Waves.wave(x * 0.005 - y * 0.007, {
      wave:  'wobble sine', t: t * 0.6, range: [45, 95]
    });
    fill(hue, 72, bri);
    rect(x, y, 4, 4);
  }
}
