Example 12 — color output

Chromatic Drift

Wave output as hue and saturation — not position. Each row's colour is determined by two independent waves sampled at that row's coordinate. No x/y movement: the wave value is the colour.

Core snippet
colorMode(HSB, 360, 100, 100);

for (let y = 0; y < height; y += 2) {
  const hue = Waves.wave(y * 0.015, {
    wave:  'classic sine',
    t:     t,
    range: [0, 360]   // → hue value
  });
  const sat = Waves.wave(y * 0.015, {
    wave:  'wobble sine',
    t:     t * 0.6,
    range: [30, 100]  // → saturation
  });
  fill(hue, sat, 88);
  rect(0, y, width, 2);
}
