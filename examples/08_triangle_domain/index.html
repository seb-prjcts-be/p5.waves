Example 08 — Domain Mapping

Interference

Two triangle waves — one horizontal, one vertical — are combined on a dot grid. Where they reinforce, a dot appears. This moiré-like interference pattern shifts as time advances. Mouse X adjusts frequency.

Core snippet
// Domain mapping: map x/y to [-freq·π, freq·π] before sampling.
// Two triangle waves on perpendicular axes create interference bands.

const freq = map(mouseX, 0, width, 0.5, 4);

const u = map(x, 0, width,  -freq*PI, freq*PI) + t;
const v = map(y, 0, height, -freq*PI, freq*PI) + t * 0.7;

const wx = Waves.wave(u, { wave: 'triangle', range: [0, 1] });
const wy = Waves.wave(v, { wave: 'triangle', range: [0, 1] });

const band = abs(wx + wy - 1);
if (band < 0.22) {
  fill(0, 0, 0, map(band, 0, 0.22, 220, 0));
  circle(x, y, 4);
}
