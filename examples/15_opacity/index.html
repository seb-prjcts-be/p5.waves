Example 15 — wave: [a, b] + mix

Morph Wave

Pass two wave names as an array and animate mix from 0 to 1 to crossfade between formulas. Each panel morphs a different pair at its own speed.

Core snippet
// mix 0 = fully waveA, mix 1 = fully waveB
const mix = (sin(frameCount * 0.008) + 1) * 0.5;

const x = Waves.wave(y * 0.014, {
  wave:      ['classic sine', 'triangle'],
  mix:       mix,
  t:         t,
  amplitude: 45
});
