Example 15 — opacity output

Fade Field

Wave output as alpha only — shapes don't move, change size or colour. Two overlapping grids at different speeds create interference patterns purely through opacity.

Core snippet
// Two waves, same grid position, different alpha
const a1 = Waves.wave(c * 0.35 + r * 0.28, {
  wave:  'classic sine',
  t:     t,
  range: [0, 220]   // → alpha
});
const a2 = Waves.wave(c * 0.28 - r * 0.35, {
  wave:  'triangle',
  t:     t * 1.6,
  range: [0, 180]   // → alpha
});

fill(0, a1);              // black circle, large
circle(cx, cy, cw * 0.72);
fill(30, 80, 180, a2);   // blue circle, small
circle(cx, cy, cw * 0.38);
