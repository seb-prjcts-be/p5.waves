Example 14 — typographic output

Breathing Type

The same word fills a 4×5 grid — one createSampler() per cell drives font size independently. A second wave controls vertical lift; a third drives opacity. Each cell breathes at its own rhythm: the word is the same, the variation is structured.

Core snippet
// One sampler per cell, seeded by flat index k
for (var k = 0; k < COLS * ROWS; k++) {
  sizeSamplers.push(
    Waves.createSampler({ seed: k * 7, range: [10, 32] })
  );
}

// In draw(), per cell:
var sz    = sizeSamplers[k].sample(k * 0.6, t);
var lift  = Waves.wave(k * 0.6, { seed: k + 20, range: [-12, 12], t: t });
var alpha = Waves.wave(k * 1.1, { seed: k + 40, range: [60, 255],  t: t });

textSize(sz);
fill(0, 0, 0, alpha);
text(WORD, cx, cy + lift);
