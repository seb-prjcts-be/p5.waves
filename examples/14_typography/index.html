Example 14 — typographic output

Breathing Type

Five createSampler() calls — one per letter — drive font size independently. A second wave controls vertical lift; a third drives opacity. Wave output as typographic property, not position.

Core snippet
// One sampler per character, each a different seed
const sizeSamplers = Array.from({ length: 5 }, (_, i) =>
  Waves.createSampler({ seed: i * 7, range: [28, 96] })
);

// In draw():
const sz    = sizeSamplers[i].sample(i * 0.6, t); // → textSize
const lift  = Waves.wave(i * 0.9 + t * 0.6,  { range: [-38, 38] }); // → y offset
const alpha = Waves.wave(i * 1.1 + t * 0.35, { range: [80, 255] });  // → opacity

textSize(sz);
fill(0, 0, 0, alpha);
text(LETTERS[i], x, height / 2 + lift);
