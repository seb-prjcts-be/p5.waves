Example 14 — typographic output

Breathing Type

4×5 grid of WAVES — each letter an independent instance. Wave formula morphs smoothly every 2 seconds. Size, lift, and opacity all crossfade between formula pairs unique to each letter.

Core snippet
// era changes every 2 s; blend crossfades 0→1 in the first 0.7 s
var era   = floor(t / INTERVAL);
var blend = constrain(map(t % INTERVAL, 0, INTERVAL * 0.35, 0, 1), 0, 1);

// per letter: morph between two formula indices
var wA = (idx * 7 + era)     % Waves.count;
var wB = (idx * 7 + era + 1) % Waves.count;

var sz    = Waves.wave(idx * 0.6, { wave: [wA, wB], mix: blend, range: [8, 28],   t: t });
var lift  = Waves.wave(idx * 0.6, { wave: [wA, wB], mix: blend, range: [-12, 12], t: t });
var alpha = Waves.wave(idx * 1.1, { wave: [wA, wB], mix: blend, range: [60, 255], t: t });
