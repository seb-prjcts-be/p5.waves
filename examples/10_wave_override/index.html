Example 10 — Wild Mode

Wild Storm

The same wave formula runs twice — left half in default smooth mode, right half with mode: 'wild' and unpredictability: 0.65. The contrast shows exactly what wild mode adds to the signal.

Core snippet
// Same wave, same time — mode:'wild' injects structured noise.
// Left half: smooth. Right half: wild + high unpredictability.

const xs = Waves.wave(y * 0.014, {
  wave: 'mountain peaks', t,
  range: [10, width / 2 - 10]        // smooth
});

const xw = Waves.wave(y * 0.014, {
  wave: 'mountain peaks', t,
  mode: 'wild',
  unpredictability: 0.65,             // wild
  range: [width / 2 + 10, width - 10]
});
