Example 07 — Wave Selection

Wave Taxonomy

Waves.list() returns all 34 wave descriptors. A 4×4 grid previews 16 of them — each cell animated live. Pass wave: N as a direct numeric index to select any formula.

Core snippet
// Waves.list() → array of { index, name } for all 34 waves.
// { wave: N } selects by direct numeric index.

const allWaves = Waves.list();   // 34 entries

for (let i = 0; i < 16; i++) {
  const idx = i * 2;   // indices 0, 2, 4 … 30
  beginShape();
  for (let y = y0 + 20; y < y0 + rh; y += 2) {
    const x = Waves.wave(y * 0.025, {
      wave:  idx,      // direct index selection
      t,
      range: [x0 + 6, x0 + cw - 6]
    });
    vertex(x, y);
  }
  endShape();
  text('#' + idx + ' ' + allWaves[idx].name, x0 + 5, y0 + 13);
}
