Ghost Delay

A loop is not a function: one x would need many y. So a height wave y = f(x) can never loop. But read a single 1D wave against a delayed copy of itself, x = wave(u) and y = wave(u + τ), and the pair closes into a loop ring. The delay τ is the only extra variable, the ghost. Sweep it and the ring breathes from an ellipse into petals. Shift is on, so the closing-group wave morphs and the whole loop family transforms. The strip along the bottom is the actual wave, with the two sampling points marked.

Core snippet
sampler = Waves.createSampler({
  group: 'ghost',              // built-in pool tuned for this delay embedding
  shift: true, range: [-1, 1]  // range:[-1,1] -> unit output (default is 100)
});

// The sampler reports its own period - no 2*PI/0.1 to hardcode. Every ghost
// wave shares it, so sweeping u over one period closes the ring, even mid-morph.
const period = sampler.period;
const tau    = period * (0.5 + 0.35 * sin(t * 0.35));   // the ghost delay

for (let i = 0; i <= N; i++) {
  const u = (i / N) * period;
  xs[i] = sampler.sample(u, t) * rad;         // x = wave(u)
  ys[i] = sampler.sample(u + tau, t) * rad;   // y = same wave, delayed
}

beginShape();
for (let i = 0; i <= N; i++) vertex(xs[i], ys[i]);
endShape(CLOSE);
