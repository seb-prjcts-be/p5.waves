Example 01 — createSampler({ shift: true })

Wave Shift

One wave line that smoothly morphs into a randomly chosen formula every few seconds. Pass shift: true — the library handles timing, random picking, and smooth easing internally.

Core snippet
var sampler = Waves.createSampler({
  shift:     true,       // auto-shift to random waves
  amplitude: 120,
  frequency: 0.6
});

// In draw — that's it:
beginShape();
for (var y = 0; y <= height; y += 3) {
  vertex(width / 2 + sampler.sample(y, t), y);
}
endShape();
