Example 01 — Global Mode

Wave Curtain

50 vertical threads each displaced horizontally by Waves.wave(). A phase offset per thread makes the displacement travel sideways, creating a flowing cloth effect.

Core snippet
// One Waves.wave() call bends each vertical thread.
// Phase offset i * 0.22 makes the wave travel sideways.

for (let i = 0; i < THREADS; i++) {
  const x0    = map(i, 0, THREADS-1, 20, width-20);
  const phase = i * 0.22;

  beginShape();
  for (let y = 0; y <= height; y += 3) {
    const dx = Waves.wave(y * 0.012, {
      wave:      'smooth step',
      t:         t + phase,
      amplitude: 14,
      frequency: 1.6
    });
    vertex(x0 + dx, y);
  }
  endShape();
}
