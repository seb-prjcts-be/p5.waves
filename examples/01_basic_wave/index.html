Example 01 — wave: [a, b] + mix

Wave Shift

One wave line that smoothly morphs into a randomly chosen formula every few seconds — using the library's built-in lerp: wave: ['a', 'b'] with an animated mix value.

Core snippet
// mix 0 → fully waveA,  mix 1 → fully waveB
var mix = morphFrame / MORPH_DURATION;
mix = mix * mix * (3 - 2 * mix);  // ease in-out

beginShape();
for (var y = 0; y <= height; y += 3) {
  var x = Waves.wave(y * 0.012, {
    wave:      [nameA, nameB],   // two formulas
    mix:       mix,              // lerp position
    t:         t,
    amplitude: 120,
    frequency: 1.2
  });
  vertex(width / 2 + x, y);
}
endShape();
