Example 03 — Instance Mode

Breathing Grid

A 28×28 grid of dots whose diameters are driven by range: [0, 1] — the wave output is a direct 0–1 fraction, usable as a scale factor without extra mapping. Instance mode.

Core snippet
// range: [0, 1] maps wave output to a 0–1 fraction.
// Use it directly as a scale — no extra map() call needed.

const val = p.waves(gx * 0.22 + gy * 0.15, {
  wave:  'smooth solid sine',
  t:     t + gx * 0.04 + gy * 0.06,
  range: [0, 1]    // fraction, not pixels
});

p.circle(
  (gx + 0.5) * cell,
  (gy + 0.5) * cell,
  val * maxDot
);
