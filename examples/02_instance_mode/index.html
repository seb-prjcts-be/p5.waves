Example 02 — Instance Mode

Sampler Orbits

Two createSampler() calls with different wave shapes drive the X and Y of 80 points, tracing Lissajous-like orbit paths. Instance mode — all p5 methods accessed via p..

Core snippet
// Two samplers — different waves — drive X and Y independently.
// Their ratio produces Lissajous-like orbit traces.

samplerX = Waves.createSampler({
  wave: 'classic sine', seed: 3,
  range: [-200, 200]
});
samplerY = Waves.createSampler({
  wave: 'wobble sine', seed: 9,
  range: [-200, 200]
});

// In draw():
const phase = (i / NUM) * p.TWO_PI * 2;
const x = p.width  / 2 + samplerX.sample(phase, t);
const y = p.height / 2 + samplerY.sample(phase + 0.8, t);
p.circle(x, y, 5);
