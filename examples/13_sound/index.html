Example 13 — sound output

Wave Synth

Three createSampler() calls drive Web Audio oscillator frequencies. A moving cursor reads the wave as a score — click to hear the result. No p5.sound required.

Core snippet
// Samplers with Hz ranges instead of pixels
const samplers = [
  Waves.createSampler({ wave: 'classic sine', range: [110, 330] }),
  Waves.createSampler({ wave: 'triangle',     range: [220, 550] }),
  Waves.createSampler({ wave: 'stepped sine', range: [330, 770] }),
];

// In draw():
const freq = samplers[i].sample(cursor * 0.018, t);
osc.frequency.value = freq;  // Web Audio API
