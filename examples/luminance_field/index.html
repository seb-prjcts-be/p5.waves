Output Shaping

Luminance Field

Two wave layers (different speeds and directions) are summed and their average drives fill brightness via range: [0, 1]. No extra mapping needed — the output is used directly as a greyscale value.

Core snippet
// range: [0, 1] → use output directly as brightness (0–220).
// Two wave layers at different speeds produce moving interference.

const v1 = Waves.wave(gx * 0.12 + gy * 0.07, {
  wave: 'smooth solid sine', t,
  range: [0, 1]
});
const v2 = Waves.wave(gy * 0.1 - gx * 0.05, {
  wave: 'classic sine', t: t * 0.7,
  range: [0, 1]
});

fill((v1 + v2) / 2 * 220);
rect(gx * cell, gy * cell, cell - 0.5, cell - 0.5);
