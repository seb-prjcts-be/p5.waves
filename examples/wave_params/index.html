Shape Parameters

Move your mouse. X controls frequency (how many waves fit), Y controls amplitude (how tall). The formula shifts automatically - drag around to feel the difference between parameters.

Core snippet
// mouseX = frequency, mouseY = amplitude
let freq = map(mouseX, 0, width, 0.15, 3.5);
let amp = map(mouseY, 0, height, 120, 8);

let val = Waves.wave(x, {
  wave: waveName,
  t: t,
  amplitude: amp,
  frequency: freq * 0.01,
  phase: i * 0.7
});
