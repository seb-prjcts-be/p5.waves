Example 21

Fabric

Material simulation without physics. Horizontal threads pinned at two points, displaced by waves. Switch the wave formula and the material changes — silk, water, burlap, rubber, grass, cable. No physics engine, just Waves.wave().

Core snippet
var MATERIALS = [
  { label: 'silk',  wave: 'classic sine',
    amp: 18, freq: 0.9, spacing: 3 },
  { label: 'burlap', wave: 'zig-zag sine',
    amp: 12, freq: 2.0, spacing: 5 },
  // ...
];

// Pin mask fades displacement at edges:
var pinMask = sin(xFrac * PI);

var dx = Waves.wave(x * 0.02 + y * 0.01, {
  wave:      m.wave,
  t:         t + frac * 2,
  amplitude: m.amp * pinMask,
  frequency: m.freq
});
