Example 18

Mood Machine

Choose a feeling, not a formula. Each mood maps to a wave type, palette, speed, and density. The same radial composition shifts character entirely based on which wave drives it.

Core snippet
var MOODS = [
  { label: 'calm',    wave: 'classic sine',
    speed: 0.004, amp: 35, freq: 0.8 },
  { label: 'anxious', wave: 'fuzzy pulse',
    speed: 0.035, amp: 50, freq: 2.2 },
  // ...
];

// Same drawing loop, different wave formula:
var offset = Waves.wave(angle * 4 + i * 0.7, {
  wave:      m.wave,
  t:         t + i * 0.3,
  amplitude: m.amp * frac,
  frequency: m.freq
});
