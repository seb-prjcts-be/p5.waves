Example 22

Particle Forces

Waves as force fields. Each particle's direction and magnitude come from Waves.wave(). The wave formula defines the system's personality — smoke drifts organically, confetti tumbles chaotically, fireflies pulse and wander.

Core snippet
var forceX = Waves.wave(pt.y * 0.01, {
  wave:      preset.wave,
  t:         t + pt.seed * 0.05,
  amplitude: preset.drift,
  frequency: preset.freq
});

var forceY = Waves.wave(pt.x * 0.01, {
  wave:      preset.wave,
  t:         t * 0.8,
  amplitude: preset.speed,
  frequency: preset.freq * 0.8
});

pt.x += forceX;
pt.y += forceY + preset.gravity;
