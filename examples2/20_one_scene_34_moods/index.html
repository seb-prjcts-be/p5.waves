Example 20

One Scene, 34 Moods

Identical grid. Identical colors. Identical objects. Only the wave formula changes. Click a number or let it auto-cycle — the formula alone determines the atmosphere.

Core snippet
// Same composition, different wave index:
var size = Waves.wave(idx * 0.6, {
  wave:  waveIdx,    // ← only this changes
  t:     t,
  range: [maxR * 0.2, maxR]
});

var brightness = Waves.wave(idx * 0.9, {
  wave:  waveIdx,    // ← same formula
  t:     t * 0.7,
  range: [30, 220]
});
