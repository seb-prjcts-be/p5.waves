Example 23

Poster Generator

p5.waves as a graphic design engine. Borders breathe, ornamental lines flow, letter spacing pulses, title characters lift and fade. Switch the wave formula to generate an entirely different poster mood — same content, different soul.

Core snippet
// Breathing borders:
var wobble = Waves.wave(x * 0.03, {
  wave: waveIdx, t: t, amplitude: 3
});
vertex(x, margin + wobble);

// Title letter lift:
var lift = Waves.wave(i * 2.5, {
  wave: waveIdx, t: t,
  amplitude: 12, frequency: 0.8
});

// Variable letter spacing:
var spacing = Waves.wave(i * 0.8, {
  wave: waveIdx, t: t * 0.5,
  range: [8, 14]
});
