API: Waves.wave(y) · wave(y, seed) · wave(y, 'name') · wave(y, {…})

The call

The second argument is optional. Pass a seed (number), a wave name (string), or a full options object — all three return the same kind of number. Start with whichever form fits.

feature: createSampler({ shift: true })

Wave Shift

One wave line that smoothly morphs into a randomly chosen formula every few seconds. Pass shift: true — the library handles timing, random picking, and smooth easing internally. Zero boilerplate.

feature: seed · floor(t / interval)

Seed as a time dimension

seed deterministically picks a wave formula. Pass floor(t / interval) as seed and the wave rotates automatically — no state, no timers, no extra variables. The formula changes; the rhythm stays recognizable.

params: amplitude · frequency · phase

Shape parameters

amplitude scales the output height. frequency compresses or stretches the wave horizontally. phase shifts it sideways. Each row fans from small (light) to large (dark) — same formula, one parameter varies.

waves: noise · grow random · fuzzy peak sine · fuzzy pulse

Noise & random waves

Several formulas produce structurally different randomness — smooth noise, growing random values, fuzzy peaks, irregular pulses. Deterministic and surprising, but always wave-shaped: structured noise, not chaos.

option: mode: 'wild' · unpredictability: 0–1

Wild mode

Any wave can run in wild mode. Left: smooth. Right: mode: 'wild' with unpredictability: 0.65. Wild mode injects position-varying noise into frequency, phase and amplitude simultaneously.

API: Waves.createSampler(options)

CreateSampler

Configure once, sample hundreds of times per frame. Two samplers with different wave shapes drive X and Y — each phase step traces an orbit unique to that combination.

→ full example 2
API: Waves.createGrid(cols, rows, options)

CreateGrid

One call generates a full 2D grid per frame. With threshold it returns a Uint8Array of 0/1 values — a binary pattern you can render any way you like.

API: Waves.createSampler() × 4 — particles

Flow fields

Four samplers — each a different wave — steer 100 particles. Configure once, sample every particle on every frame. Swap the wave names to change the flow pattern — the motion shifts character, not coherence.

feature: t is just a number

Time is a number

There is no built-in clock. Pass any number as t — move the mouse to scrub through time. Freeze it, rewind it, slow it down for frame captures.
