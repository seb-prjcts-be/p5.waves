p5.waves

Wave sampling helpers for p5.js. Always returns a number.
Think of noise(y) — but with 34 curated wave formulas you can freely combine.

What this library does

p5.waves gives you a curated list of 34 wave formulas you can sample with a single number input. Each formula is a small math expression that takes x. You pass your position (y) and get a number back — ready to use as an offset, color value, size, or anything else.

Core
34 wave formulas

From classic sine and triangle to random noise, fuzzy peaks and chaotic tangent — each with a name and index.

Animation
Time parameter t

Pass t: frameCount * 0.01 and every wave animates smoothly — no extra code needed.

Output
Range normalisation

With range: [-80, 80] the output maps automatically to your coordinate space.

Chaos
Wild Mode

Set mode: 'wild' and control how chaotically the wave deviates with unpredictability (0–1).

2D
createGrid()

Generates a full grid in one call — as Float32Array (range) or Uint8Array (binary via threshold).

Reusable
createSampler()

Configure once, sample hundreds of times. Two samplers with different seeds give independent axes — no correlation.

Core API

  • Waves.wave(y, options) Single-shot sampling — returns one number. Second param: number (seed), string (name), or options object.
  • Waves.createSampler(options) → { sample(y, t) } Reusable sampler. Configuration is resolved once; ideal for loops and grids.
  • Waves.createGrid(cols, rows, options) → { sample(t) } Returns Float32Array or Uint8Array for a full grid. Combines two waves (row + col direction).
  • Waves.list() / Waves.count / Waves.data Discovery — inspect all 34 formulas with name, index and expression.
