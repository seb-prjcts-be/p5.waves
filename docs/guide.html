Installation

Load p5.js first, then p5.waves. Order matters.

<script src="https://cdn.jsdelivr.net/npm/p5@2.2.2/lib/p5.js"></script> <script src="https://cdn.jsdelivr.net/gh/seb-prjcts-be/p5.waves@v1.0.0/p5.waves.js"></script> <script src="sketch.js"></script>

Mental Model

Think of Waves.wave(y) the same way you think of noise(y) in p5.js — pass a coordinate, get a number back. That number is ready to use as an offset, size, color, or anything else.

The difference: instead of one Perlin noise field, you have 34 curated wave formulas to choose from, each with a distinct character — but all periodic and structurally legible. Switching between them produces structured surprise: unexpected variation that never degenerates into chaos.

Waves.wave()

The simplest entry point. Call it anywhere — no setup needed. Always returns a number.

Calling forms

Waves.wave(y) // default wave, seed 0 Waves.wave(y, 3) // number → seed 3 selects a wave Waves.wave(y, 'triangle') // string → wave by name Waves.wave(y, { wave: 'triangle' }) // options object

All options

OptionDescriptionDefault
waveWave name (string) or index (number 0–33)seed-determined
seedInteger — deterministically picks a wave via hashing. Use for stable variety across objects.0
tTime offset — drives animation. Pass frameCount * 0.01 or millis()/1000.0
amplitudeScales normalized output to [-amplitude, +amplitude]. Ignored when range is set.100
range[min, max] — normalises output to this interval.null
frequencyInput multiplier — tighter or looser wave cycles.1
phaseInput offset — shifts the wave left or right.0
mode'stable' or 'wild' — wild injects position-varying noise.'stable'
unpredictability0–1 intensity for wild mode. Has no effect in stable mode.0

All 34 wave formulas are internally normalized to [-1, 1] before amplitude is applied. This means amplitude: 100 always produces output in [-100, 100], regardless of which formula is active. Switching formulas — manually or via shift — never causes scale jumps.

note Seed vs index — two different numbers:
Waves.wave(y, 3) — the shorthand form treats 3 as a seed. It gets hashed into a wave selection, so seed 3 always picks the same wave, but it's not wave #3.
Waves.wave(y, { wave: 3 }) — the wave property is a direct index. You get exactly wave #3 from the list.
Use { wave: N } when you need a specific formula. Use the seed shorthand when you want each object in a set to get its own consistent wave without caring which one.

Examples

// Animated wave line function draw() { background(245); beginShape(); for (let y = 0; y <= height; y += 4) { const x = width / 2 + Waves.wave(y, { wave: 'classic sine', t: frameCount * 0.01, amplitude: 80 }); vertex(x, y); } endShape(); }
// Range normalisation — output mapped to [–120, 120] const x = Waves.wave(y, { wave: 'classic sine', t: frameCount * 0.01, range: [-120, 120] }); circle(width / 2 + x, y, 5);
// Range [0, 1] — use as a position fraction const x01 = Waves.wave(y, { wave: 'classic sine', t: frameCount * 0.01, range: [0, 1] }); circle(x01 * width, y, 5);

Waves.createSampler()

Configure once, sample many times. Resolves the wave and options on creation, then calls to sample() are fast and clean.

const s = Waves.createSampler({ wave: 'triangle', range: [-80, 80] }); s.sample(y); // → number at position y s.sample(y, t); // → number at position y with time t

The sampler also exposes .waveIndex and .waveName for inspection.

Why use a sampler instead of Waves.wave()?

ReasonDetail
Readabilitys.sample(x) reads like noise(x) — one source, many samples.
PerformanceConfig is resolved once. In a 40×40 grid or 1000-point loop you only call sample().
RepeatabilityFixing a seed gives stable, reproducible results — essential for generative work.
Independent axesTwo samplers with different seeds produce two unrelated signals. One shared sampler would correlate them.

Two independent axes (WEBGL / 3D)

let samplerX, samplerZ; function setup() { createCanvas(600, 600, WEBGL); samplerX = Waves.createSampler({ seed: 0, range: [-80, 80] }); samplerZ = Waves.createSampler({ seed: 1, range: [-80, 80] }); } function draw() { background(245); const t = frameCount * 0.01; for (let y = -200; y <= 200; y += 30) { for (let x = -200; x <= 200; x += 30) { push(); translate(x + samplerX.sample(y, t), 0, y + samplerZ.sample(y, t)); sphere(4); pop(); } } }

Shift — auto-cycle through random formulas

Pass shift: true and the sampler automatically picks a new random wave every few seconds, morphing smoothly between them. Time (t) stays explicit — the shift is derived from the t you pass.

var sampler = Waves.createSampler({ shift: true, amplitude: 50, frequency: 0.6 }); function draw() { background(245); t += 0.014; beginShape(); for (var y = 0; y <= height; y += 3) { vertex(width / 2 + sampler.sample(y, t), y); } endShape(); }
OptionDescriptionDefault
shiftEnable auto-cyclingfalse
shiftIntervalSeconds to hold each wave3
shiftDurationSeconds for the morph transition1

The shift sampler exposes getters for UI feedback:

GetterReturns
.waveNameCurrent formula name
.targetNameNext formula name (during morph)
.mixMorph progress 0–1
.shiftingtrue while morphing
.waveIndexCurrent formula index

Shift also works on Waves.wave() directly — pass shift: true in the options object. The sampler version is preferred because it caches per-era compilations and exposes the getters above.

Waves.createGrid()

Generates a full 2D grid of wave values in one call. Returns a typed array — either Float32Array (continuous values) or Uint8Array (binary 0/1).

const g = Waves.createGrid(cols, rows, options); const cells = g.sample(t); // → Float32Array or Uint8Array, length = cols × rows // Access a cell: cells[row * g.cols + col]
OptionDescriptionDefault
waveRowWave for the row direction (name or index)seed-determined
waveColWave for the column direction (name or index)seed-determined (different)
seedAuto-selects two different waves when waveRow/waveCol are omitted0
range[min, max] → Float32Array with normalised valuesnull
thresholdCells above → 1, below → 0. Returns Uint8Array. Overrides range.null
speedTime scale factor applied to the t argument of sample()1

how it works Each cell value is the sum of waveRow sampled at the row position and waveCol sampled at the column position. Both positions are mapped to [0, 2π] before sampling.

Binary grid (threshold → Uint8Array)

let g; function setup() { createCanvas(560, 420); g = Waves.createGrid(14, 14, { waveRow: 'classic sine', waveCol: 'triangle', threshold: 0, speed: 1 }); } function draw() { background(245); const cells = g.sample(frameCount * 0.02); const cw = width / g.cols, ch = height / g.rows; noStroke(); for (let r = 0; r < g.rows; r++) { for (let c = 0; c < g.cols; c++) { fill(cells[r * g.cols + c] === 1 ? 0 : 255); rect(c * cw, r * ch, cw, ch); } } }

Continuous grid (range → Float32Array)

const g = Waves.createGrid(20, 20, { seed: 0, range: [0, 1] }); const cells = g.sample(frameCount * 0.01); // cells[i] is a float in [0, 1] — use directly as a grey value, size, alpha…

Wild Mode

Set mode: 'wild' to inject position-varying noise simultaneously into frequency, phase, and amplitude. Control the intensity with unpredictability (0 = stable, 1 = pure chaos).

for (let y = 0; y < height; y += 10) { const x = Waves.wave(y, { wave: 'pulse', t: frameCount * 0.01, mode: 'wild', unpredictability: 0.45, range: [-160, 160] }); circle(width / 2 + x, y, 5); }

With internal normalization, wild mode is now predictable across all formulas. Higher unpredictability values are safe — the output stays within the amplitude bounds.

Works identically with createSampler() — just add mode: 'wild' and unpredictability to the options.

Animation & Time

The t parameter shifts the wave input over time: internally, x = (y + t) × frequency + phase. Two independent knobs control animation speed:

KnobControls
t multiplierHow fast the wave moves (motion speed)
frameRate(n)How many frames per second p5 renders (capture speed)
// Fixed timestep — motion speed is independent of frame rate let simTime = 0; function draw() { simTime += 1 / 30; const x = Waves.wave(y, { wave: 'classic sine', t: simTime * 6, range: [-120, 120] }); }
// Slow down for screen recording or GIF capture function setup() { createCanvas(600, 600); frameRate(6); // keep t multiplier small to match slower frame rate }

Instance Mode

In instance mode, use p.waves(), p.createWaveSampler(), and p.createWaveGrid() — or keep using the global Waves.* methods, which work in both modes.

new p5(function(p) { p.setup = function() { p.createCanvas(400, 400); }; p.draw = function() { p.background(245); p.beginShape(); for (let y = 0; y <= p.height; y += 4) { const x = p.width / 2 + p.waves(y, { wave: 'classic sine', t: p.frameCount * 0.5, amplitude: 80 }); p.vertex(x, y); } p.endShape(); }; });

p5.js Version Compatibility

p5.waves targets p5.js 2.x. All examples in this showcase run on p5@2.2.2. No deprecated APIs are used — the library is a plain IIFE that adds three methods to p5.prototype and exports a global Waves object.

The library does not call any p5.js internals. As long as p5.prototype exists when the script loads, it will work.
