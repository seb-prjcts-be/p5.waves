p5.waves Guide

34 wave shapes. One function. Pass a number in, get a number back.

Install

Load p5.js first, then p5.waves. Order matters.

<script src="https://cdn.jsdelivr.net/npm/p5@2.2.2/lib/p5.js"></script> <script src="https://cdn.jsdelivr.net/gh/seb-prjcts-be/p5.waves@v3.0.0/p5.waves.js"></script> <script src="sketch.js"></script>

Your First Sketch

Copy this. Run it. You should see a wave line moving across the canvas.

function setup() { createCanvas(600, 400); } function draw() { background(245); noFill(); stroke(0); beginShape(); for (let x = 0; x <= width; x += 3) { let y = Waves.wave(x, { wave: 'mountain peaks', t: millis() / 1000, amplitude: 80 }); vertex(x, height / 2 + y); } endShape(); }

That's it. Waves.wave() takes a position (x), returns a number. Use that number for anything — y-position, size, color, rotation, whatever.

Three Ways to Call It

// Simplest — random wave, no options Waves.wave(x); // Pick a wave by name Waves.wave(x, 'triangle'); // Full control Waves.wave(x, { wave: 'triangle', t: millis() / 1000, amplitude: 50 });

The Options That Matter

You only need a few. The rest are optional.

Must-know

OptionWhat it doesDefault
waveWhich wave shape to use. Name ('sine'), index (0–33), or two names for blending (['sine', 'triangle']).random
tTime. Makes the wave move. Pass millis() / 1000 or your own counter. The library never moves time on its own.0
amplitudeHow tall the wave is. Output goes from -amplitude to +amplitude.100

Good to know

OptionWhat it doesDefault
rangeMap output to a custom range. [0, 255] gives you a value between 0 and 255. Overrides amplitude.null
frequencyHow tight the wave cycles are. Higher = more squished together.1
seedPicks a wave based on a number. Same seed = same wave every time. Good for giving each object its own wave.0
shiftSet to true and the wave automatically switches to a new random formula every few seconds, with a smooth blend.false

mode'stable' (normal) or 'wild' (adds wobble to everything).'stable'

mixBlend between two waves when wave is an array. 0 = first wave, 1 = second.0.5

Wave Shift

The killer feature. One flag and the wave switches to a random formula every few seconds, with a smooth blend in between. Different every time you load the page.

let sampler = Waves.createSampler({ shift: true, amplitude: 60, shiftInterval: 4, // hold each wave 4 seconds shiftDuration: 1.5 // morph over 1.5 seconds }); function draw() { background(245); let t = millis() / 1000; beginShape(); for (let y = 0; y <= height; y += 3) { vertex(width / 2 + sampler.sample(y, t), y); } endShape(); // What's playing right now? text(sampler.waveName, 10, 20); // current wave name text(sampler.shifting, 10, 40); // true during morph text(sampler.targetName, 10, 60); // next wave name text(sampler.mix, 10, 80); // morph progress 0–1 }

Shift also works on Waves.wave() directly — add shift: true to the options. The sampler version is better because it caches the wave lookups and gives you the .waveName / .shifting / .mix getters.

Morph

Blend two wave shapes together. Pass an array of two names and a mix value.

let y = Waves.wave(x, { wave: ['sine', 'triangle'], mix: mouseX / width, // 0 = pure sine, 1 = pure triangle t: millis() / 1000, amplitude: 40 });

Both waves are squeezed to [-1, 1] independently before blending. range works normally in morph mode.

createSampler()

When you call the same wave hundreds of times per frame (particles, grids, loops), create a sampler first. It resolves the wave once and gives you a fast .sample() method.

let s = Waves.createSampler({ wave: 'triangle', range: [-80, 80] }); // In draw: s.sample(y); // at position y s.sample(y, t); // at position y with time t s.sample(y, t, mix); // morph mode: override blend s.waveName; // the wave name

Accepts all the same options as Waves.wave() — including shift, mode, mix, etc.

Two samplers for 3D

let sx = Waves.createSampler({ seed: 0, range: [-80, 80] }); let sz = Waves.createSampler({ seed: 1, range: [-80, 80] }); // Each sampler picks a different wave (different seed) // Use one for X displacement, one for Z

createGrid()

Fills a 2D grid with wave values in one call. Two waves (one for rows, one for columns) are combined per cell.

let g = Waves.createGrid(14, 14, { waveRow: 'classic sine', waveCol: 'triangle', threshold: 0, // cells above 0 → 1, below → 0 speed: 1 }); let cells = g.sample(t); // Uint8Array of 0s and 1s // Access cell: cells[row * g.cols + col]
OptionWhat it doesDefault
waveRowWave for the row direction.random (from seed)
waveColWave for the column direction.random (from seed)
seedPicks two different waves automatically.0
rangeMap output to a range. Returns Float32Array.null
thresholdBinary mode. Returns Uint8Array of 0/1. Overrides range.null
speedTime scale factor.1

heads up The output array is reused between .sample() calls. If you need to keep a snapshot, copy it: new Float32Array(g.sample(t)).

Wild Mode

Adds wobble to frequency, phase, and amplitude at the same time. The wave stays recognizable but gets distorted.

let y = Waves.wave(x, { wave: 'pulse', t: millis() / 1000, mode: 'wild', unpredictability: 0.45, amplitude: 80 });

unpredictability goes from 0 (identical to stable) to 1 (maximum distortion). Wild mode is about 5x slower than stable — keep that in mind for large loops.

Time

The library has no clock. You pass t on every call. This means you can:

  • Pause: stop changing t
  • Rewind: decrease t
  • Scrub: tie t to mouse position
  • Slow down: use a smaller increment
// Mouse-controlled time let t = map(mouseX, 0, width, 0, 10); let y = Waves.wave(x, { wave: 'sine', t: t, amplitude: 50 });

Seed vs Index

Two different ways to pick a wave with a number. Don't mix them up.

Waves.wave(x, 3) // seed 3 → hashed to some wave (not wave #3) Waves.wave(x, { wave: 3 }) // index 3 → exactly wave #3 (square)

Use index when you want a specific wave. Use seed when you want each object to get its own consistent wave without caring which one.

API Access Modes

Waves.* always works. In p5 global mode, shorter names are also available.

Always availablep5 global modep5 instance mode
Waves.wave(y, opts)waves(y, opts)p.waves(y, opts)
Waves.createSampler(opts)createWaveSampler(opts)p.createWaveSampler(opts)

Also available: Waves.list() (all formulas), Waves.count (34), Waves.data (raw formula array).
