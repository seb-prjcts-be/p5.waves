p5.waves Guide

Everything you need to use the library — from installation to advanced patterns.

Installation

Load p5.js first, then p5.waves. Order matters.

<script src="https://cdn.jsdelivr.net/npm/p5@2.2.2/lib/p5.js"></script> <script src="https://cdn.jsdelivr.net/gh/seb-prjcts-be/p5.waves@v2.1.1/p5.waves.js"></script> <script src="sketch.js"></script>

Mental Model

Think of Waves.wave(y) the same way you think of noise(y) in p5.js — pass a coordinate, get a number back. That number is ready to use as an offset, size, color, or anything else.

The difference: instead of one Perlin noise field, you have 34 curated wave formulas to choose from, each with a distinct character — but all periodic and structurally legible. Switching between them produces structured surprise: unexpected variation that never degenerates into chaos.

Waves.wave()

The primary entry point. Call it anywhere — no setup needed. Always returns a number.

Calling forms

Waves.wave(y) // default wave, seed 0 Waves.wave(y, 3) // number → seed 3 selects a wave Waves.wave(y, 'triangle') // string → wave by name Waves.wave(y, { wave: 'triangle' }) // options object — single wave Waves.wave(y, { wave: ['sine', 'triangle'], mix: 0.5 }) // morph between two waves

All options

OptionTypeDescriptionDefault
wavestring, number, or arrayWave name (string), index (number 0–33), or morph pair ['a', 'b'].seed-determined
seednumberInteger — deterministically picks a wave via hashing. Use for stable variety across objects.0
tnumberTime offset — drives animation. Pass millis()/1000 or your own counter. The library never increments t internally.0
amplitudenumberOutput multiplier. Ignored when range is set.100
range[min, max]Normalises output to this interval. Overrides amplitude.null
frequencynumberInput multiplier — tighter or looser wave cycles.1
phasenumberInput offset — shifts the wave left or right.0
modestring'stable' or 'wild' — wild injects position-varying noise into frequency, phase, and amplitude.'stable'
unpredictabilitynumber0–1 intensity for wild mode. Has no effect in stable mode.0
mixnumber0–1 blend factor when wave is an array of two names. 0 = first wave, 1 = second wave.0.5
shiftbooleanEnable auto-cycling — picks a new random wave every shiftInterval seconds, with a smooth morph transition.false
shiftIntervalnumberSeconds to hold each wave before morphing to the next.3
shiftDurationnumberSeconds for the morph transition between waves.1

note Seed vs index — two different numbers:
Waves.wave(y, 3) — the shorthand form treats 3 as a seed. It gets hashed into a wave selection, so seed 3 always picks the same wave, but it's not wave #3.
Waves.wave(y, { wave: 3 }) — the wave property is a direct index. You get exactly wave #3 from the list.
Use { wave: N } when you need a specific formula. Use the seed shorthand when you want each object in a set to get its own consistent wave without caring which one.

Return value

Always a single number. The internal formula is: x = (y + t) × frequency + phase. The formula output is then scaled by amplitude, or mapped to range if set.

Examples

// Animated wave line function draw() { background(245); beginShape(); for (let y = 0; y <= height; y += 4) { const x = width / 2 + Waves.wave(y, { wave: 'classic sine', t: frameCount * 0.01, amplitude: 80 }); vertex(x, y); } endShape(); }
// Range normalisation — output mapped to [–120, 120] const x = Waves.wave(y, { wave: 'classic sine', t: frameCount * 0.01, range: [-120, 120] }); circle(width / 2 + x, y, 5);
// Range [0, 1] — use as a position fraction const x01 = Waves.wave(y, { wave: 'classic sine', t: frameCount * 0.01, range: [0, 1] }); circle(x01 * width, y, 5);

Morph — blending two waves

Pass an array of two wave names (or indices) to wave and control the blend with mix. Both waves are evaluated at the same position, then linearly interpolated.

// Blend sine and triangle — mix driven by mouseX const x = Waves.wave(y, { wave: ['sine', 'triangle'], mix: mouseX / width, // 0 = pure sine, 1 = pure triangle t: frameCount * 0.01, amplitude: 80 });

note range normalisation is not applied in morph mode. The output is scaled by amplitude only. This is a deliberate design decision — interpolating normalised values would distort the morph shape.

Waves.createSampler()

Configure once, sample many times. Resolves the wave and all options on creation — calls to .sample() are fast and clean.

const s = Waves.createSampler({ wave: 'triangle', range: [-80, 80] }); s.sample(y); // → number at position y s.sample(y, t); // → number at position y with time t

When shift: true, the sampler auto-cycles through random wave formulas. It returns an object with additional getters for UI feedback:

Property / MethodTypeDescription

.waveNamestring (getter)Name of the currently active wave formula.
.targetNamestring (getter)Name of the next wave formula (the one being morphed toward).
.mixnumber (getter)Current morph progress 0–1. Is 0 while holding, increases during transitions.
.shiftingboolean (getter)true while a morph transition is in progress.

Why use a sampler instead of Waves.wave()?

ReasonDetail
Readabilitys.sample(x) reads like noise(x) — one source, many samples.
PerformanceConfig is resolved once. In a 40×40 grid or 1000-point loop you only call sample().
RepeatabilityFixing a seed gives stable, reproducible results — essential for generative work.
Independent axesTwo samplers with different seeds produce two unrelated signals. One shared sampler would correlate them.

Two independent axes (WEBGL / 3D)

let samplerX, samplerZ; function setup() { createCanvas(600, 600, WEBGL); samplerX = Waves.createSampler({ seed: 0, range: [-80, 80] }); samplerZ = Waves.createSampler({ seed: 1, range: [-80, 80] }); } function draw() { background(245); const t = frameCount * 0.01; for (let y = -200; y <= 200; y += 30) { for (let x = -200; x <= 200; x += 30) { push(); translate(x + samplerX.sample(y, t), 0, y + samplerZ.sample(y, t)); sphere(4); pop(); } } }

Shift example

var sampler = Waves.createSampler({ shift: true, amplitude: 120, frequency: 0.6, shiftInterval: 4, // hold each wave for 4 seconds shiftDuration: 1.5 // morph over 1.5 seconds }); function draw() { background(245); t += 0.014; beginShape(); for (var y = 0; y <= height; y += 3) { vertex(width / 2 + sampler.sample(y, t), y); } endShape(); // Show current wave name and morph status text(sampler.waveName, 10, 20); if (sampler.shifting) { text('→ ' + sampler.targetName + ' (' + nf(sampler.mix, 1, 2) + ')', 10, 40); } }

Shift also works on Waves.wave() directly — pass shift: true in the options object. The sampler version is preferred because it caches per-era compilations and exposes the getters above.

Waves.createGrid()

Generates a full 2D grid of wave values in one call. Returns a typed array — either Float32Array (continuous values) or Uint8Array (binary 0/1).

const g = Waves.createGrid(cols, rows, options); const cells = g.sample(t); // → Float32Array or Uint8Array, length = cols × rows // Access a cell: cells[row * g.cols + col]

Arguments

ArgumentTypeDescriptionDefault
colsnumberNumber of columns. Clamped to minimum 1.10
rowsnumberNumber of rows. Clamped to minimum 1.10
optionsobjectConfiguration object (see below).{}

Options

OptionTypeDescriptionDefault
waveRowstring or numberWave for the row direction (name or index).seed-determined
waveColstring or numberWave for the column direction (name or index). Always different from waveRow when auto-selected.seed-determined
seednumberAuto-selects two different waves when waveRow/waveCol are omitted.0
range[min, max]Normalises output — returns Float32Array with values in this interval.null
thresholdnumberCells above this value → 1, below → 0. Returns Uint8Array. Overrides range.null
speednumberTime scale factor applied to the t argument of .sample(t).1

Return value

Property / MethodTypeDescription
.colsnumberNumber of columns (as resolved from input).
.rowsnumberNumber of rows (as resolved from input).
.sample(t)function → typed arrayEvaluate the full grid at time t. Returns Float32Array (when range is set) or Uint8Array (when threshold is set), length = cols × rows. Access cell [row, col] at index row * cols + col.

how it works Each cell value is the sum of waveRow sampled at the row position and waveCol sampled at the column position. Both positions are mapped to [0, 2π] before sampling.

note The output array is reused between .sample() calls for performance. If you need to keep a snapshot, copy it: new Float32Array(g.sample(t)).

Binary grid (threshold → Uint8Array)

let g; function setup() { createCanvas(560, 420); g = Waves.createGrid(14, 14, { waveRow: 'classic sine', waveCol: 'triangle', threshold: 0, speed: 1 }); } function draw() { background(245); const cells = g.sample(frameCount * 0.02); const cw = width / g.cols, ch = height / g.rows; noStroke(); for (let r = 0; r < g.rows; r++) { for (let c = 0; c < g.cols; c++) { fill(cells[r * g.cols + c] === 1 ? 0 : 255); rect(c * cw, r * ch, cw, ch); } } }

Continuous grid (range → Float32Array)

const g = Waves.createGrid(20, 20, { seed: 0, range: [0, 1] }); const cells = g.sample(frameCount * 0.01); // cells[i] is a float in [0, 1] — use directly as a grey value, size, alpha…

Wild Mode

Set mode: 'wild' to inject position-varying noise simultaneously into frequency, phase, and amplitude. Control the intensity with unpredictability (0 = stable, 1 = pure chaos).

OptionTypeDescriptionDefault
modestring'stable' — clean wave output. 'wild' — noise-modulated output.'stable'
unpredictabilitynumber0 = no effect (identical to stable). 1 = maximum distortion. Clamped to 0–1.0

Internally, wild mode applies 4 noise modulations per sample: frequency scaling, phase offset, amplitude scaling, and a carrier blend. This makes it ~5× slower than stable mode — see Performance.

for (let y = 0; y < height; y += 10) { const x = Waves.wave(y, { wave: 'pulse', t: frameCount * 0.01, mode: 'wild', unpredictability: 0.45, range: [-160, 160] }); circle(width / 2 + x, y, 5); }

Works identically with createSampler() — just add mode: 'wild' and unpredictability to the options.

Animation & Time

The t parameter shifts the wave input over time: internally, x = (y + t) × frequency + phase. Two independent knobs control animation speed:

KnobControls
t multiplierHow fast the wave moves (motion speed)
frameRate(n)How many frames per second p5 renders (capture speed)

The library has no internal clock. Time is always explicit — you pass t on every call. This enables reproducibility, composability, and manual time control (pause, reverse, scrub).

// Fixed timestep — motion speed is independent of frame rate let simTime = 0; function draw() { simTime += 1 / 30; const x = Waves.wave(y, { wave: 'classic sine', t: simTime * 6, range: [-120, 120] }); }
// Slow down for screen recording or GIF capture function setup() { createCanvas(600, 600); frameRate(6); // keep t multiplier small to match slower frame rate }

p5.js Version Compatibility

p5.waves targets p5.js 2.x. All examples in this showcase run on p5@2.2.2. No deprecated APIs are used — the library is a plain IIFE that adds three methods to p5.prototype and exports a global Waves object.

The library does not call any p5.js internals. As long as p5.prototype exists when the script loads, it will work.

Performance

Every Waves.wave() call evaluates a compiled formula. The cost depends on which features you combine.

Relative cost per sample

FeatureCostNotes
wave(y)1×Baseline — single formula evaluation
wave(y, { range })~1.2×Adds a stats lookup (cached after first call)
wave(y, { wave: ['a','b'], mix })2×Two formula evaluations + interpolation
wave(y, { shift: true }) during transition2×Two formulas + smoothstep blending
wave(y, { mode: 'wild' })~5×4 extra noise evaluations per sample
createGrid(n, m).sample(t)n × m × aboveEvery cell is a full evaluation

Tips

  • Use createSampler() when calling the same config repeatedly — it resolves parameters once at creation instead of on every call.
  • createGrid() reuses its output array between calls. Do not store the returned array for later — it will be overwritten on the next .sample() call. Copy it if you need to keep it: new Float32Array(grid.sample(t)).
  • Grid size is soft-limited to 250×250 (62,500 cells). Larger grids trigger a console warning. A 100×100 grid with wild mode = 50,000 noise evaluations per frame.
  • Use Waves.benchmark(config, iterations) to measure your configuration: returns { iterations, ms, callsPerMs }.
